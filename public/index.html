ProofGuard

A payment-guard agent for the zkVerify Agent Games (Wildcard Track). It screens a proposed stablecoin payment against a fixed, published policy — and returns a Groth16 zero-knowledge proof that its decision follows the policy. A proof for a wrong decision cannot be generated: the circuit constrains decision == 1 if and only if every check passes.

Policy (all four must pass to approve)

  1. amount ≤ maxAmount — otherwise AMOUNT_OVERFLOW
  2. balance ≥ minBalance — otherwise INSUFFICIENT_BALANCE
  3. currentBlock < expiryBlock — otherwise EXPIRED
  4. recipient == expectedRecipient — otherwise RECIPIENT_MISMATCH

The proof is bound to one taskId (sha256, first 31 bytes, public signal 10). The agent never signs or sends a transaction and holds no keys. It only judges.

Circuit: payment_guard.circom (Groth16, BN254, 1,179 constraints, 10 public inputs). Source: see the repo README. Built for zkVerify Agent Games, Season 01, Wildcard Track.
