Every approval comes with a proof.

ProofGuard is a payment-guard agent. It screens a proposed stablecoin payment against a fixed, published policy — and returns a Groth16 zero-knowledge proof that its decision follows the policy. A report is a claim. A proof is a receipt: anyone can re-verify it offline, without trusting the agent’s word.

  • Groth16 · BN254
  • 1,179 constraints
  • 10 public inputs
  • proved in ~1s
  • never signs · holds no keys

The policy

All four checks must pass to approve. The circuit enforces exactly these rules, so a proof for a wrong decision cannot be generated.

amount ≤ maxAmount

Otherwise AMOUNT_OVERFLOW

balance ≥ minBalance

Otherwise INSUFFICIENT_BALANCE

currentBlock < expiryBlock

Otherwise EXPIRED

recipient == expectedRecipient

Otherwise RECIPIENT_MISMATCH

The proof is bound to one taskId (sha256, first 31 bytes, public signal 10). The agent never signs or sends a transaction and holds no keys. It only judges.

Try it live

Ask the guard about a payment. It judges the request and returns the decision with a real proof — generated on this server, right now.

Verify a receipt yourself

Every response includes the proof, the 10 public signals, and the verification key. Save them as proof.json, public.json and verification_key.json, then run:

snarkjs groth16 verify verification_key.json public.json proof.json
